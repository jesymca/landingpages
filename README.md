# LinkBio Venezuela (`landingpages`)

Plataforma SaaS Linktree multi-perfil construida con Next.js App Router, Turso libSQL, NextAuth, Cloudflare R2 y Tailwind CSS v4, con panel Super Admin multi-ruta y API Externa v1 para creación masiva automatizada de perfiles.
